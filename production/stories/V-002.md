# Story V-002: Player Controller — Walk + Jump + Gravity + Ground Collision

> **Status**: In Progress
> **Type**: Logic
> **Estimated**: 2–3h
> **Depends on**: V-001
> **Unlocks**: V-003 (buster), V-004 (dash), V-005 (wall jump), V-008 (enemy hit), V-009 (HP)

## Goal

A `CharacterBody2D`-based action-platformer player with horizontal walking,
gravity-driven falling with terminal velocity clamp, ground collision via
`move_and_slide`, jump on edge-trigger of the jump button, and "feels good"
forgiveness via coyote time, jump buffer, and variable jump height. No dash,
no shooting, no wall interactions yet — those are later stories.

## Acceptance Criteria

- [ ] `src/scripts/player.gd` — `class_name Player extends CharacterBody2D`
- [ ] Exports (data-driven, no inline magic numbers):
  - [ ] `walk_speed: float = 90.0`            (px/s horizontal)
  - [ ] `jump_velocity: float = -280.0`       (px/s; negative = up)
  - [ ] `gravity: float = 800.0`              (px/s²)
  - [ ] `terminal_velocity: float = 360.0`    (px/s; cap on `velocity.y`)
  - [ ] `coyote_time: float = 0.1`            (s; ~6 frames @ 60fps)
  - [ ] `jump_buffer: float = 0.1`            (s; ~6 frames @ 60fps)
  - [ ] `short_hop_factor: float = 0.4`       (multiplier on `velocity.y` when jump released early)
- [ ] State (private):
  - [ ] `_coyote_timer: float` — counts down after leaving floor
  - [ ] `_jump_buffer_timer: float` — counts down after jump pressed in air
  - [ ] `_jump_was_pressed: bool` — last-frame snapshot for edge detection
  - [ ] `_jump_held: bool` — true while jump button held (for variable jump cutoff)
- [ ] In `_physics_process(delta)` (skipped if `Game.test_mode`):
  - [ ] Apply gravity: `velocity.y = min(velocity.y + gravity * delta, terminal_velocity)`
  - [ ] Read horizontal input: `velocity.x = Input.get_axis("ui_left", "ui_right") * walk_speed`
  - [ ] Edge-detect jump press → either jump (if grounded or coyote-valid) or arm jump_buffer
  - [ ] If grounded with positive `_jump_buffer_timer` → consume buffer + jump
  - [ ] If jump released while `velocity.y < 0` → variable jump cutoff (`velocity.y *= short_hop_factor`)
  - [ ] Track grounded transitions: when leaving floor without jumping → start coyote_timer
  - [ ] Decrement `_coyote_timer` and `_jump_buffer_timer` each frame
  - [ ] Call `move_and_slide()`
- [ ] Public testable methods (so tests don't need a SceneTree):
  - [ ] `func tick_movement(delta: float, input_x: float, jump_pressed: bool, jump_held: bool, is_grounded: bool) -> void`
        — pure logic step; updates `velocity` + timers without `move_and_slide`. Lets tests run without physics.
- [ ] Doc comment on the class + every `func` (per CLAUDE.md).
- [ ] Wired into `src/scripts/levels/stage_1.gd` so the title-screen → stage flow shows a player on a flat floor (placeholder ColorRect ground at y=180).

## Implementation Notes

- Use a `CollisionShape2D` child with a `RectangleShape2D` of size 12×16 (tweak later for sprite).
- Floor visual: `ColorRect` at the player's spawn area in `stage_1.gd` with a `StaticBody2D` for the actual collider. ColorRect alone is *not* a physics body.
- The `tick_movement` split is a deliberate testability seam: `_physics_process`
  reads the world (`is_on_floor()`, real input), then delegates the math to
  `tick_movement`. Tests can call `tick_movement` directly with synthesized inputs.
- Edge detection: at frame start, `var jump_held: bool = Input.is_action_pressed("jump")`, then `var jump_pressed: bool = jump_held and not _jump_held_last`, then update `_jump_held_last = jump_held` at frame end. Use `"jump"` action (Space + Z, defined in V-001), not `ui_accept`.
- `Game.test_mode` guard: `if Game.test_mode: return` at the top of `_physics_process` so spawned-in-test player nodes don't auto-step.

## Tuning Note

`jump_velocity = -280` with `gravity = 800` yields apex height = `280²/(2·800) ≈ 49 px` ≈ **3.0 cells** (cell = 16 px), not 4.5 as I claimed earlier in chat. We can ship as-is and re-tune once visual feel is in (V-007 stage layout will tell us if this clears the platform heights). If we want ~4.5-cell jump, bump `jump_velocity` to ~−340.

## Tests (BLOCKING — Logic story)

`src/tests/unit/player/test_player_movement.gd` (GUT):

- [ ] `test_gravity_accumulates_below_terminal` — start `velocity.y = 0`, call `tick_movement(0.016, 0, false, false, false)` (airborne, no input), assert `velocity.y > 0` and `velocity.y < terminal_velocity`
- [ ] `test_gravity_clamps_at_terminal_velocity` — start `velocity.y = 350`, tick airborne, assert `velocity.y == 360.0` (or `is_equal_approx`)
- [ ] `test_walk_left_sets_negative_x_velocity` — tick with `input_x = -1`, assert `velocity.x == -90.0`
- [ ] `test_walk_right_sets_positive_x_velocity` — tick with `input_x = 1`, assert `velocity.x == 90.0`
- [ ] `test_no_input_zeroes_x_velocity` — tick with `input_x = 0`, assert `velocity.x == 0.0`
- [ ] `test_jump_press_while_grounded_sets_jump_velocity` — `tick_movement(0.016, 0, jump_pressed=true, jump_held=true, is_grounded=true)`, assert `velocity.y == -280.0`
- [ ] `test_jump_press_while_airborne_does_not_jump` — start `velocity.y = 0`, tick with `is_grounded=false, jump_pressed=true`, assert `velocity.y > 0` (only gravity, no jump)
- [ ] `test_coyote_time_allows_jump_after_leaving_ground` — tick grounded once → tick airborne immediately with `jump_pressed=true` within coyote window, assert jump fires (`velocity.y == -280`)
- [ ] `test_coyote_time_expires_after_window` — tick grounded → tick airborne for 0.15s (past 0.1s window) with no input → tick `jump_pressed=true`, assert no jump (`velocity.y > 0` from gravity only)
- [ ] `test_jump_buffer_consumed_on_landing` — tick airborne with `jump_pressed=true` (arms buffer) → tick airborne again (no press, buffer still hot) → tick grounded (no fresh press), assert jump fires
- [ ] `test_jump_buffer_expires_after_window` — arm buffer → tick airborne for 0.15s without re-pressing → tick grounded, assert no jump
- [ ] `test_variable_jump_cutoff_when_released_early` — jump (`velocity.y == -280`) → next tick with `jump_held=false`, assert `velocity.y == -112` (=−280 × 0.4)
- [ ] `test_variable_jump_no_cutoff_when_falling` — `velocity.y = 100` (falling), `jump_held=false`, assert `velocity.y` unchanged by short-hop logic (only gravity adds)
