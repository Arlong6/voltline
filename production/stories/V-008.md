# Story V-008: Basic Enemy — Patrolling Sweeper

> **Status**: In Progress
> **Type**: Logic
> **Estimated**: 2h
> **Depends on**: V-002, V-003 (for bullet collision)
> **Unlocks**: V-010 (boss room), all combat-driven content

## Goal

A `CharacterBody2D` enemy that patrols horizontally between two `patrol_min_x`
and `patrol_max_x` x-bounds on whatever floor it spawns on. Reverses
direction at the bounds. Killed in one hit by a player bullet (Area2D
`body_entered`). Touching the player triggers the player's damage signal
(see V-009 for player respawn).

## Acceptance Criteria

### Enemy class
- [ ] `src/scripts/enemy.gd` — `class_name Enemy extends CharacterBody2D`
- [ ] Tunables (data-driven via @export):
  - [ ] `walk_speed: float = 30.0`
  - [ ] `gravity: float = 800.0`
  - [ ] `terminal_velocity: float = 360.0`
  - [ ] `direction: int = 1` (initial)
  - [ ] `patrol_min_x: float = 0.0`
  - [ ] `patrol_max_x: float = 100.0`
- [ ] State: `is_alive: bool = true`
- [ ] `tick_movement(delta)` — pure logic step, sets velocity.x from direction × walk_speed, applies gravity (clamped), reverses direction at patrol bounds (if direction sign would push past the relevant bound)
- [ ] `_physics_process(delta)` — short-circuits on `Game.test_mode` or `not is_alive`; calls tick_movement then move_and_slide
- [ ] `die()` — sets `is_alive = false` and `queue_free()`s the enemy
- [ ] `_draw()` — placeholder sweeper bot silhouette: red 14×8 body + yellow eye on facing side + 3× 2×3 leg rects underneath
- [ ] `src/scenes/enemy.tscn` — root CharacterBody2D with `collision_layer = 4`, `collision_mask = 1` (collides with World floor only), `RectangleShape2D` size `Vector2(14, 12)`, plus an Area2D child `HurtBox` with `collision_mask = 2` (detects player) emitting `body_entered`

### Bullet collision wiring
- [ ] `Bullet._ready()` connects `body_entered` to `_on_body_entered`
- [ ] `_on_body_entered(body)` calls `body.die()` if `body is Enemy and body.is_alive`, then `queue_free()` the bullet (so it despawns on either an enemy or a wall hit)
- [ ] Skipped under `Game.test_mode`
