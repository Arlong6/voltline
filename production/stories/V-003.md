> **Status**: In Progress
> **Type**: Logic

> **Unlocks**: V-006 (charge shot), V-008 (enemy hit detection)

## Goal

Player can fire a horizontal cyan bullet on the rising edge of the `shoot`
action (X key). Bullet travels at constant speed in the player's current
facing direction and despawns when it leaves the viewport. A small cooldown
between shots prevents one-frame spam. Introduces the player's `facing`
state, which V-004 (dash) and later visuals also consume.

- [ ] New public state `var facing: int = 1` on `Player` (-1 left, 1 right)
- [ ] In `tick_movement`: if `input_x != 0.0` AND not currently dashing, update `facing = int(signf(input_x))`

- [ ] `_draw()` adds a 2×2 white "muzzle" pip on the player's facing edge so direction is visible

## Implementation Notes

- Bullet uses `Area2D` (not CharacterBody2D) — projectiles in this game don't
  slide/bounce. Area2D detects overlaps cheaply via `area_entered` /
  `body_entered` signals; we wire those in V-008 when enemies exist.
- For v0.2 there are no walls or enemies, so bullets simply fly off-screen
  and despawn. The collision layer/mask is forward-set so we don't have to
  edit the scene later.
- Spawning at `get_parent()` (stage_1) instead of as a child of the player
  ensures bullets persist independently of player state and don't move with
  the player after firing.
